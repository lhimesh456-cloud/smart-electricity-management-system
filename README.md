# ⚡ Smart Electricity Management System

### Smart Energy Monitoring, Electricity Bill Estimation and Energy Conservation

## 📌 About the Project

The Smart Electricity Management System is a web-based educational project developed to help users monitor electricity consumption, estimate electricity bills and manage household energy usage.

The system supports state selection for Andhra Pradesh (AP), Telangana (TS) and Tamil Nadu (TN).

It provides an interactive dashboard with electricity management tools and energy-saving recommendations.

## 🎯 Objectives

* Calculate estimated electricity bills.
* Monitor household electricity consumption.
* Compare electricity costs between states.
* Manage electrical appliances.
* Track monthly electricity budgets.
* Maintain electricity bill history.
* Encourage energy conservation.

## ✨ Features

1. **Smart Dashboard** – Displays electricity consumption and estimated bills.
2. **Bill Calculator** – Estimates electricity charges based on entered units.
3. **State Selection** – Supports AP, Telangana and Tamil Nadu.
4. **District Selection** – Allows users to select their district.
5. **Appliance Management** – Calculates appliance-wise energy consumption.
6. **Energy Analytics** – Displays consumption charts.
7. **Budget Manager** – Tracks estimated bills against a monthly budget.
8. **Bill History** – Stores previous bill estimates.
9. **State Comparison** – Compares illustrative electricity costs.
10. **CSV Export** – Downloads bill history.
11. **Energy Saving Tips** – Provides recommendations to reduce electricity usage.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Select your state and district.
5. Enter electricity consumption units.
6. Calculate your estimated bill.
7. Add appliances and monitor energy usage.
8. Set your monthly electricity budget.

## 🧮 Appliance Consumption Formula

Monthly Energy Consumption:

`(Power in Watts × Daily Usage Hours × Quantity × 30) / 1000`

The result is measured in kWh (units).

## ⚠️ Important Disclaimer

The currently included electricity tariff values are illustrative demonstration values, not verified official tariffs.

Actual electricity bills depend on the latest applicable state tariff orders, consumption slabs, subsidies, fixed charges, taxes and other adjustments.

This project is intended for educational demonstration and not for official billing.
